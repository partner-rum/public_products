# Rumberg — витрина структурных продуктов

Публичный сайт: **https://invest.rumberg.ru/**

Структурные продукты для квалифицированных инвесторов: доска прайсинга с котировками,
размещённые выпуски, первичные размещения, дайджест инвестиционных идей и скринер ставок
денежного рынка. Компания — [Rumberg Capital](https://rumberg.ru/).

## Страницы

```
index.html        — главная
board.html        — доска инструментов: варранты, дисконтные облигации,
                    защита капитала, бустеры, автоколлы
instrument.html   — карточка инструмента: график выплат и пример расчёта
screener.html     — лучшие ставки на срок до года: вклады, накопительные
                    счета, фонды денежного рынка, короткие ОФЗ
placements.html   — размещённые выпуски с текущими котировками
offerings.html    — выпуски на размещении
digest.html       — дайджест инвестиционных идей
about.html        — библиотека: как устроен каждый тип продукта
company.html      — о компании
onepager.html     — печатная версия карточки инструмента
```

## Как устроено

Статический сайт без сборки и без фреймворков — чистые HTML, CSS и JavaScript.
Каждая страница самодостаточна: свои стили и скрипты внутри файла. Публикуется
GitHub Pages из ветки `main`, домен подключён через `CNAME`.

Данные лежат отдельно от разметки в `data/*.js` — обычные JS-файлы с объектами
(`instruments.js` — инструменты доски, `placements.js` — размещённые выпуски,
`rates.js` — ставки для скринера, `digest.js` — выпуски дайджеста, `lib.js` —
описания типов продуктов и формулы выплат). Страницы читают их простым
`<script src>` и рисуют содержимое на клиенте.

Обновление данных — питоновскими скриптами, которые перезаписывают файлы в `data/`
и коммитят их в репозиторий; сайт обновляется сам через минуту после пуша.

## Локальный просмотр

Достаточно открыть `index.html` в браузере — сайт работает прямо с диска.
